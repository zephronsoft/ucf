# Umesh Chandra Foundation (UCF) Website

A modern, responsive website for the Umesh Chandra Foundation built with HTML5, CSS3, and JavaScript. Dedicated to social service and community development with comprehensive programs and initiatives.

## About UCF

The Umesh Chandra Foundation is dedicated to uplifting communities through various social welfare programs, educational initiatives, and humanitarian services, carrying forward the legacy and vision of our founder.

**Registration:** Regd.No.351 of 2024

## Website Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices

## Customization Guide

### 🎨 Branding Updates
1. **Logo**: Replace images in `/images/` folder
2. **Colors**: Update CSS custom properties in `:root`
3. **Content**: Modify text in HTML sections
4. **Contact Info**: Update foundation details throughout

### 📝 Content Management
- **Programs**: Add/modify program details in HTML and JavaScript
- **Statistics**: Update hero section numbers and labels
- **Testimonials**: Replace quotes and attribution
- **Events**: Modify upcoming events in JavaScript modals

### 🎛️ Technical Customization
- **CSS Variables**: Centralized color and spacing control
- **Responsive Design**: Mobile-first approach with progressive enhancement
- **Performance**: Optimized images and efficient animations
- **Accessibility**: Semantic HTML and proper contrast ratios
