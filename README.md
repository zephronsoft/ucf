# Political Party Website

A modern, responsive website for a political party built with HTML5, CSS3, and JavaScript. The design is inspired by the Indian National Congress website (inc.in) with modern UI/UX best practices.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations
- **Navigation**: Fixed header with smooth scrolling navigation
- **Hero Section**: Eye-catching banner with party branding
- **Key Issues**: Showcases the party's main focus areas
- **In Focus**: Latest news and updates section
- **Interactive Elements**: Hover effects and click handlers
- **Performance Optimized**: Fast loading with optimized images

## File Structure

```
├── index.html          # Main HTML file
├── style.css           # All CSS styles
├── script.js           # JavaScript functionality
├── images/             # Party images directory
│   ├── flag.jpeg       # Party flag
│   ├── flag with aim.jpeg # Vision image
│   ├── info.jpeg       # Information image 1
│   ├── info2.jpeg      # Information image 2
│   └── aim.jpeg        # Party aim image
└── README.md           # This file
```

## How to Use

1. **Setup**: Simply open `index.html` in any modern web browser
2. **Customization**: 
   - Edit the HTML content in `index.html` to match your party's information
   - Modify colors, fonts, and styles in `style.css`
   - Add more functionality in `script.js`
   - Replace images in the `images/` folder with your party's photos

## Customization Guide

### Changing Party Information

1. **Party Name**: Update "People's Party" in the HTML file
2. **Colors**: Modify the CSS color scheme to match your party colors
3. **Content**: Replace all text content with your party's messaging
4. **Images**: Replace the placeholder images with your actual party images

### Adding New Sections

To add new sections, follow this pattern:

```html
<section id="new-section" class="new-section">
    <div class="container">
        <h2>Section Title</h2>
        <!-- Your content here -->
    </div>
</section>
```

Then add corresponding CSS styles for the new section.

### Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px - 1199px  
- **Mobile**: Below 768px

## Performance Tips

1. Optimize images before uploading
2. Use WebP format for better compression
3. Minify CSS and JavaScript for production
4. Enable gzip compression on your server

## Deployment

1. **GitHub Pages**: Push to a GitHub repository and enable Pages
2. **Netlify**: Drag and drop the folder to Netlify
3. **Traditional Hosting**: Upload all files to your web server
